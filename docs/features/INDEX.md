## Status definitions

| Status | Meaning |
| --- | --- |
| `proposed` | Problem identified; scope and owner are being clarified. |
| `specified` | Requirements and acceptance criteria are documented. |
| `building` | Implementation is in progress within the agreed scope. |
| `validating` | Functional and quality checks are running. |
| `shipped` | Released with acceptance criteria met. |
| `paused` | Blocked by a decision, dependency, or unresolved issue. |
